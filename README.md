# Find Maximum Value in a List using Python Function

## Problem Statement
Write a Python program to find the maximum value from a list of numbers using a user-defined function.

## Aim
To implement a Python function that returns the maximum element from a list while handling edge cases.

## Features
- Takes user input
- Finds maximum value using function
- Handles empty list condition

## Technologies Used
- Python

## Sample Input
12 45 67 23 89

## Sample Output
Maximum value is: 89

## Learning Outcome
- Understanding of functions in Python
- Working with lists
- User input handling
- Basic edge case handling
